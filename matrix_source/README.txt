design_id
Enter the ID of the matrix this row belongs to, for example M001, M002, or M003. All rows with the same design_id will be combined into one matrix.

block_type
Enter picture if the cue will be a clear image. Enter text if the cue will be a written word.

block_order
Enter 1 if this block should appear first in the matrix, or 2 if it should appear second.

target_object
Enter a simple English ID for the target object, for example strawberry, shoe, or cup. Use the same spelling everywhere.

target_label_ka
Enter the main Georgian name of the target object.

accepted_labels_ka_optional
Enter any other Georgian labels that should also be accepted for the target. Separate multiple labels with semicolons. Leave blank if there are no alternatives.

mooney_file
Enter the path to the target object’s Mooney image, for example:

stimuli/strawberry_mooney.jpg

target_clear_file
Enter the path to the clear image of the target object, for example:

stimuli/strawberry_clear.jpg

cue_validity
Enter correct if the cue represents the same object as the target. Enter incorrect if the cue represents a different object.

cue_object
Enter the English ID of the cue object. For a correct cue, this should be the same as target_object. For an incorrect cue, it should be a different object.

cue_label_ka
Enter the Georgian label of the cue object. In text blocks, this is the word that will be shown to the participant.

cue_clear_file
For picture blocks, enter the path to the clear image used as the cue. For text blocks, leave this blank.

notes
Optional. Add any comments about the object or cue pairing.

row_check
Do not edit this column. It automatically checks the row for basic mistakes.
